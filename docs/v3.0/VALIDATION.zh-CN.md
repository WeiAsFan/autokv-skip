# v3.0 代码验证记录

日期：2026-09-09。本记录对应当前 `v3.0` 实现，仅记录开发验证，不是模型实验结果。真实数据确定和 GPU 验证按[运行手册](RUNBOOK.zh-CN.md)执行。

完整回归共 170 项通过，其中新增 v3 测试 41 项；原有 129 项继续通过。Windows 的默认临时路径包含 `ADMINI~1` 短名称，导致两项旧测试将它与 `Administrator` 长名称误判为不同目录。本次只在测试进程中将临时路径解析为统一的绝对路径，未修改旧版逻辑或全局环境。

在工作区执行的回归命令：

```powershell
$env:PYTHONUTF8='1'
@'
import tempfile, unittest, sys
from pathlib import Path
tempfile.tempdir = str(Path(tempfile.gettempdir()).resolve())
result = unittest.TextTestRunner(verbosity=1).run(unittest.defaultTestLoader.discover('tests'))
sys.exit(not result.wasSuccessful())
'@ | python -
```

这些开发测试不属于服务器实验的前置步骤。

| 范围 | 验证内容 |
|---|---|
| 数据 | 原始 SQuAD/HotpotQA 结构适配；来源隔离、不同问题、分层嵌套前缀；证据保护；开发与正式数据分开生成仍一致 |
| 评分 | 键值配对、多值集合、QA 别名与空答案；任务约束不能被总分改善抵消；浮点边界和来源组重采样 |
| 增量运行 | 模拟 HTTP/进程下，32→96→256 只生成 256 次；中断保留已完成行；损坏尾行恢复；输入改变不能误用缓存 |
| 搜索 | 全层扩展、条件收益变化、宽度 2 的路径选择、并列扩评、集合去重、反向删层、显式预算终止 |
| 主流程 | 冻结后测试；测试失败不重新选层；P0 去重；质量/容量负结果；跨运行测试重用标记；无 Git 的源码目录可建立运行 |
| 完整联调 | 生成数据→实际运行器→评分→报告→归档；模拟服务质量通过但容量不足时保持负结果，重新运行不增加生成请求 |
| 导出 | 成功与未完成运行、仅 CLI 失败日志、输入副本、分片还原；已有来源导入不联网；镜像分页与截断单题重取 |

此外核对了四个新命令的 `--help`、文档命令与配置字段。HotpotQA 原站在当前网络超时；公开镜像的实际响应结构已核查。完整镜像下载的分页行为使用夹具验证，尚未在本地下载全量语料。

当前未验证的部分是：完整真实语料在目标 tokenizer 下生成、64 条开发数据的 BF16 难度、真实 vLLM 混合 dtype、选层耗时、1024 条独立测试质量和实测 KV 容量。模拟分数和容量仅用于检验控制流程，不能当作这些结果的证据。
